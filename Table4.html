Education & Learning Experience

My journey in technology started during my school years when I first used a computer for basic tasks. My interest grew when I learned about programming in high school. I started with Python because its syntax was easy to understand. Later, I studied C and C++ which helped me understand how computers work at a low level, including memory, pointers, and data structures. When I joined university, I chose web development as my focus area. The internet is everywhere today, and building websites is a skill that is always in demand. My first step was learning HTML. HTML taught me how to create the structure of a webpage using tags like head, body, div, and section. After HTML, I learned CSS. CSS is used for styling. I practiced CSS properties like color, margin, padding, border, flexbox, and grid. I spent many hours making my pages look clean and modern. JavaScript was the next step. With JavaScript, I learned how to make websites interactive. I built small projects such as a to-do list, a calculator, and a image gallery. These projects taught me how to use functions, events, and DOM manipulation. Debugging JavaScript errors also improved my problem-solving skills. A major part of this course was learning Git and GitHub. Git is a version control system that helps developers track changes in code. GitHub is a platform to host code and collaborate with others. Using GitHub Pages to deploy this website was a new and exciting experience for me. It taught me how to make my work public and share it with teachers and friends. Outside of class, I follow online tutorials from MDN Web Docs and W3Schools. I also watch YouTube channels on web development. I have joined coding communities on Discord where students share projects and help each other. I believe learning never stops in tech because new frameworks and tools come out every year. This Web Programming course gave me hands-on practice. The assignment to write 500 words here made me think about my progress. I now feel confident in building a responsive website, writing clean code, and deploying it online. My next goal is to learn backend development with Node.js and databases like MySQL. I also want to contribute to open-source projects in the future. In short, my learning experience has been a mix of theory, practice, and self-study. Every error I faced taught me something new. I am excited to keep building and learning more about the web.
