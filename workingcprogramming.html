Hackerrank Practice, Certificate or Badge

During last semester, I completed many C programming challenges on Hackerrank.com. Hackerrank is one of the best platforms to practice coding and improve problem-solving skills. I started with the "C Basics" domain where I solved problems on data types, input-output, loops, and conditional statements. After that, I moved to "Arrays and Strings" and "Functions" modules. The most challenging part for me was pointers and memory management, but after practicing 20+ problems I became comfortable with it. I completed a total of 45 problems on Hackerrank in C. My profile shows a 3-star badge in C programming. The certificate I earned after completing the "C (Basic) Skill Assessment" is shown above. Practicing on Hackerrank helped me a lot in my university exams because the questions were very similar to our lab tasks. It also taught me how to write clean, optimized, and error-free code under time pressure. I learned how to read problem statements carefully, test my code with edge cases, and debug efficiently. Some of my favorite problems were "For Loop in C", "Sum of Digits", "Pattern Printing", and "Student Marks Sum". I also participated in a 30-day coding challenge on Hackerrank which improved my consistency. Overall, Hackerrank made C programming more practical and fun for me. It is a platform I will continue to use even after this course.

Sololearn Practice, Certificate

In addition to Hackerrank, I also used Sololearn.com to learn C programming from scratch. Sololearn has an interactive, mobile-friendly course that is perfect for beginners. The course is divided into modules like Introduction to C, Variables and Data Types, Control Flow, Arrays, Functions, Structures, and Pointers. I completed all 12 modules and passed the final exam with 95% marks. The certificate is attached above. What I liked most about Sololearn was its bite-sized lessons and built-in code editor. I could practice code directly on my phone during travel time. The community Q&A section also helped me when I got stuck. Through Sololearn, I built small projects like a "Simple Calculator", "Number Guessing Game", and "Student Grade System". These projects helped me understand how to combine different C concepts in one program. The section on Structures was very useful because later we used structures for file handling in university labs. I spent more than 30 hours on Sololearn last semester. The gamified learning with XP points and streaks kept me motivated. Sololearn gave me a strong theoretical base, and Hackerrank gave me practical problem-solving practice. Together, they made my C programming foundation very strong. I recommend Sololearn to any student who is new to C because the explanations are very simple and beginner-friendly.

University Lab Practice

Apart from online platforms, most of my learning came from university labs. We completed more than 15 lab assignments in C. Some of them were: Calculator using switch-case, Prime Number Checker, Fibonacci Series, Matrix Addition and Multiplication, File Read/Write Programs, and Structure-based Student Record System. These labs taught me how to plan a program, write algorithms on paper first, and then implement them in code. My teacher also focused on debugging and memory errors, which is very important in C. All my lab files are saved in my GitHub repository for reference.
